## 🚀 Featured Project

### Indonesian Cyberbullying Text Classification

**Repository:** [deteksi-cyberbullying-discord](https://github.com/FallenStars31/deteksi-cyberbullying-discord)

An academic research project focused on classifying Indonesian-language Discord messages into six categories: insult, threat, hate speech, harassment, exclusion, and non-cyberbullying.

The project explored how traditional machine learning and natural language processing techniques can be applied to Indonesian text classification.

**Key components**
- Text preprocessing, including case folding, tokenization, slang normalization, stopword removal, and stemming.
- Text representation using TF-IDF.
- Classification using Multinomial Naive Bayes.
- Model evaluation and cross-validation.
- A Streamlit application for interacting with the classification system.
- Supabase/PostgreSQL integration for storing messages and classification results.

**Reported result:** 80.2% accuracy for the six-class classification experiment.

Beyond the reported performance, this project helped me understand the importance of dataset quality, preprocessing decisions, evaluation methodology, and error analysis. It also highlighted that a model's usefulness cannot be determined by accuracy alone; its limitations and misclassifications need to be examined as well.

The experience encouraged me to approach machine learning as an iterative process of experimentation, evaluation, and improvement rather than simply selecting an algorithm and measuring its final score.

## How I Approach Problems

I value a structured and evidence-oriented approach to technical work.

- **Understand the problem:** Identify the objective, requirements, and constraints before choosing an approach.
- **Explore the data or system:** Examine available information and look for relevant patterns, issues, or assumptions.
- **Experiment and evaluate:** Test solutions and use appropriate evidence to assess their results.
- **Recognize limitations:** Investigate errors, edge cases, and weaknesses instead of relying on a single performance metric.
- **Iterate and learn:** Use findings from each implementation to improve the next version.

I'm particularly interested in the reasoning behind technical decisions and in understanding the trade-offs involved in building practical solutions.
